# responsive-layout1

Projeto acadêmico desenvolvido com **HTML5 e CSS3**, com foco na criação de layouts responsivos e na adaptação de páginas web para diferentes tamanhos de tela.

## Sobre o projeto

O projeto consiste em uma página web composta por seis cartões com imagens e conteúdo, organizados de maneira adaptável para computadores e dispositivos móveis.

## Objetivo

Praticar conceitos fundamentais de desenvolvimento front-end, trabalhando com estruturação HTML, estilização CSS e técnicas de responsividade.

## Tecnologias utilizadas

- **HTML5:** estruturação e organização do conteúdo.
- **CSS3:** estilização e posicionamento dos elementos.
- **Flexbox:** organização e distribuição dos cartões.
- **Media Queries:** adaptação do layout para diferentes resoluções.
- **GitHub Pages:** hospedagem gratuita da página.

## Características

- Layout composto por seis cartões.
- Organização em duas colunas em telas maiores.
- Adaptação para três colunas em dispositivos móveis.
- Utilização de Flexbox para distribuição dos elementos.
- Responsividade por meio de Media Queries.
- Prevenção de rolagem horizontal indesejada.
